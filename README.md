## 📖 Overview

This repository contains the official code, models, and documentation for my Bachelor's thesis: **Group Activity Recognition for Sports Video Analysis**.

In team sports, understanding the collective behavior of players is crucial for tactical analysis, automated broadcasting, and performance evaluation. This project proposes a deep learning framework designed to recognize multi-agent activities by analyzing spatiotemporal interactions between individuals in sports videos.

### Key Objectives:
<!-- - **Player Detection & Tracking:** Extracting bounding boxes and tracking player movements across video frames. -->
- **Feature Extraction:** Capturing spatial features (poses, positions) and temporal dynamics using Convolutional Neural Networks (CNNs).
- **Group Activity Classification:** Modeling the interactions between players to classify the overall group activity (e.g., *Spike, Set, Pass* in Volleyball / *Foul, Goal* in Soccer).
